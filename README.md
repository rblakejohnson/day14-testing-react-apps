# Day 14: Testing React Apps

## Setup

```bash
npm install
npm run test
```

To view the components in the browser:

```bash
npm run dev
```

---

## Files

- `src/demos/` — Lecture demo components and tests (`Greeting`, `Counter`, `SimpleReviewForm`)
- `src/exercises/Exercises.test.jsx` — In-class Exercises 1–5
- `src/components/ReviewForm.test.jsx` — Day 14 Mini-Project tests (includes 1 bug to catch and fix in `ReviewForm.jsx`)
